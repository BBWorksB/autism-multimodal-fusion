# Multimodal Fusion of Eye-Tracking and Facial Features for Early Autism Diagnosis

An AI system that combines facial imagery and eye-tracking behavioral data 
to assess Autism Spectrum Disorder (ASD) risk using multimodal deep learning.

## Project Status
🚧 In Progress — Expected completion: 28th February 2026

## Overview
This project builds a multimodal fusion model that jointly analyzes:
- **Facial features** — extracted from labeled facial imagery
- **Eye-tracking features** — gaze patterns, fixation duration, saccade behavior

The system outperforms single-modality baselines and is deployed 
as an interactive Streamlit web application.

## Structure
- `notebooks/` — EDA and model development notebooks
- `src/` — modular source code (preprocessing, models, training, evaluation)
- `app/` — Streamlit deployment
- `docs/` — methodology and model card

## Stack
